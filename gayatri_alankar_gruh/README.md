# 💎 Gayatri Alankar Gruh

A modern, responsive and elegant single-page website created for **Gayatri Alankar Gruh**, a jewellery store located in Gandhi Nagar, Kalamb, Maharashtra.

The website is designed with a premium dark-and-gold visual style and provides customers with store information, services, gallery, testimonials, FAQs, contact options and direct WhatsApp communication.

## ✨ Features

- 🏠 **Hero Section** with store introduction and call-to-action buttons
- 💍 **About Section** with store information and location
- 🛍️ **Services & Selection** section
- 🖼️ **Responsive Jewellery Gallery**
- ⭐ **Customer Testimonials**
- ❓ **FAQ Section**
- 📞 **Click-to-Call** store contact
- 📍 **Google Maps Directions & Embedded Map**
- 💬 **WhatsApp Enquiry Form**
- 🟢 **Floating WhatsApp Button**
- 📱 **Responsive mobile navigation**
- ✨ **Scroll reveal animations**
- 🎨 Premium dark, gold and cream color theme
- 🔤 Google Fonts and Font Awesome icons
- 📅 Dynamic copyright year
- ♿ Basic semantic HTML and accessibility attributes

## 🧰 Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Google Fonts**
  - Cormorant Garamond
  - Inter
- **Font Awesome 6**
- **Google Maps Embed**

## 💬 WhatsApp Enquiry

The contact form collects:

- Customer name
- Phone number
- Jewellery enquiry/message

After submission, the information is formatted and opened in WhatsApp using the store's WhatsApp number.

The website also includes a floating WhatsApp button for quick enquiries.

## 🎨 Design

The interface follows a luxury jewellery aesthetic using:

- Dark background
- Gold accents
- Cream/white typography
- Rounded cards
- Glass-like translucent elements
- Large serif headings
- Responsive layouts
- Hover effects
- Scroll reveal animations

The main CSS theme variables include background, surface, gold, cream, muted text, borders, shadows and border radius values.

## 📱 Responsive Design

The website adapts to:

- Desktop
- Tablet
- Mobile

At smaller screen sizes:

- Desktop navigation changes to a hamburger menu
- Content grids become single-column layouts
- Gallery adapts to a mobile grid
- Typography and spacing are adjusted
- Contact and review sections become mobile-friendly

## 🚀 Run Locally

No backend or build system is required.

1. Download or clone the project.
2. Make sure `index.html` and the `assets` folder are in the correct structure.
3. Open `index.html` in a browser.

For development, you can also use **VS Code Live Server**.

## 🌐 Deployment

Because this is a static HTML/CSS/JavaScript website, it can be deployed on services such as:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel
- Any standard static web hosting service

No server-side runtime is required for the current version.

## ⚙️ Customization

### Store details

Update the phone number, address, hours and Plus Code in `index.html` if the business information changes.

### Gallery

Replace the images inside the `assets/` directory with the store's actual jewellery/product photography while keeping the referenced filenames, or update the image paths in `index.html`.

### Social Media

Instagram and Facebook buttons are currently placeholders and should be replaced with the store's actual profile URLs before production use.

### Reviews

The displayed testimonials are sample website content. Replace them with verified customer reviews before using them as real business testimonials.

The review-form implementation present in the source is currently commented out. The source notes that a permanent public review system would require a database or review service.

## 🔐 Privacy & Security Notes

The current website is primarily frontend/static.

- The enquiry form does not store customer data in a database.
- WhatsApp is used to send enquiry information.
- Do not add sensitive customer information to public page content.
- Use HTTPS when deploying the website publicly.

## 📝 Important Notes

- Internet access is required for Google Fonts, Font Awesome CDN, Google Maps and WhatsApp links.
- The current map and directions point to Gayatri Alankar Gruh in Kalamb.
- Store hours shown on the page should be verified with the business before relying on them.
- Replace sample gallery images and testimonials with the business's own approved content for production.
